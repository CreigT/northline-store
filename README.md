# Store

One storefront prepared for Vercel. It does not contain sample products, sample prices, or sample orders.

Import this repo on Vercel. Framework preset: Other. Add Stripe payment links and an owner key only when a real seller is ready. Do not invent catalog rows.

What is built: pages, a checkout redirect, an owner key, a price check, a stock check, an order file, a ship mark, and a week count.

What is not built: more than one seller, accounts, a database, Stripe webhooks, Connect payouts, email, shipping labels, or legal pages.
