# Merchant store

Step 1. One merchant. One public link: `/s/store`. Products live on that merchant in `data/merchant.json`.

No sample products are included.

Import on Vercel. Framework preset: Other. Set `OWNER_ACCESS_CODE` before saving a merchant. Set `STRIPE_PAYMENT_LINK_SHOP` before Buy can charge.

Not in this step: a second merchant, accounts, a database, webhooks, or payouts.
